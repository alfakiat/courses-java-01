Question 2

Given a = 5 and b = 3, what is the value of total after executing this statement?

int total = b++ * ++a / 2 + --b;

Value of total:

Answer Key (For Instructor)

  1. 23
    • x starts at 7.
    • x += 3 → x = 10.
    • x *= 2 → x = 20.
    • x += 4 → x = 24.
    • x-- → x = 23.

  2. 12
    • b++ evaluates to 3 (post-increment, so b becomes 4 in memory).
    • ++a evaluates to 6 (pre-increment, a becomes 6).
    • The multiplication happens first: 3 * 6 = 18.
    • The division happens next: 18 / 2 = 9.
    • --b evaluates to 3 (pre-decrement, b goes from 4 down to 3).
    • The addition happens last: 9 + 3 = 12.
