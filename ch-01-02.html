Concept 2.1

What is Programming?

Programming means writing instructions for a computer to follow. A program is simply a set of instructions that tells a computer exactly what to do.

Instructor Note

Use the control panel below to demonstrate the workflow. Emphasize that the computer does nothing without the programmer providing the step-by-step instructions.
