Data Types & Memory Allocation

Learn how Java defines variable types, allocates memory, and enforces type safety.

MEMORY LAYOUT

Primitive vs Reference

Direct value vs reference to an object

What does a variable hold?

A simplified model of local variables in a method frame. Objects and arrays live on the heap. Primitive fields can also live inside heap objects. References are not Java-accessible numeric addresses; physical layout is JVM-dependent.
Primitive types
Eight built-in types: boolean, byte, short, int, long, float, double, and char.
Reference types
Class types (including String), interface types, and array types. A reference can point to an object or be null.
Type safety begins at compilation
int age = 20;       // valid
// age = "twenty";  // compile-time error: String cannot be assigned to int
A variable’s declared type limits which values it can hold.
