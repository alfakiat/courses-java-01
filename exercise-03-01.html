Java basic operators

15 exercises, from beginner to expert. Predict, trace, explain, debug, and write code. Discuss each question before revealing its answer. Every snippet starts independently inside main().

Lab setup: JDK and Apache NetBeans IDE · Week 3 · In lab.

Before starting: Review primitive types, variables, = versus ==, and print statements. Wrap any snippet in public class Main { public static void main(String[] args) { /* snippet */ } }.

Operator guide (higher to lower precedence): postfix ++/--; prefix ++/-- and !; * / %; + -; < <= > >=; == !=; &&; ||; assignment. Parentheses group expressions. Precedence determines grouping; Java evaluates operands left to right. && and || may skip the right operand.

Walkthrough Understand ++ and --

Before Exercise 08

++ adds 1; -- subtracts 1. Prefix changes the variable before supplying its value to the expression. Postfix supplies the current value, then changes the variable. Each example below starts independently with int a = 10;.

What is the output, and what is a afterward? Each row starts with a = 10.
FormWhat is the output, and what is a afterward?

System.out.println(++a);

Remember: both forms update the variable during evaluation of the expression. Postfix does not wait until the next statement. When used alone as a statement, a++; and ++a; both simply increase a by 1; the difference matters when the expression’s value is used. The same applies to decrement.

The left n++ supplies 5 and leaves n = 6. In the multiplication, ++n supplies 7, so 7 * 2 = 14. The last n-- supplies 7 and leaves n = 6. Result: 5 + 14 - 7 = 12. Multiplication has higher precedence, but Java still evaluates operands left to right. For everyday code, separate these changes into statements.
