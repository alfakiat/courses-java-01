Concept 4.1

Compilers vs. Interpreters

Both translate high-level code into machine code, but their architecture differs completely in when and how a separate executable file is generated.

Key Architectural Difference
  • Compiler: Translates entirely upfront to generate a standalone .exe or .class file. Execution happens later.
  • Interpreter: No new file is created. Translates and executes line-by-line in real-time.
