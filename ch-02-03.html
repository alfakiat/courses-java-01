Syntax Structure & Comments

Read a Java program, locate its entry point, and see how comments affect output.

PROGRAM STRUCTURE
● ● ● HelloWorld.java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}

The public class HelloWorld belongs in HelloWorld.java. Capitalization must match.

COMMENTS LAB

Code the compiler ignores

Single-line comments begin with //. Block comments begin with /* and end with */.

CONSOLE OUTPUT
