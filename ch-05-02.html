Rules that keep switch valid
For this classic colon-style switch: common selectors are byte, short, char, int and String (also enums and their supported integral wrappers). Use compatible constant case values, a colon, and no duplicates. This lecture uses no preview features.
SYNTAX · Click a highlighted part to explore it
int choice = 2;
switch (choice) {
     break;
     break;
}
boolean selectors, variable case labels, duplicate cases, and a condition such as case mark >= 50 are also invalid in this classic syntax.

Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Choose 1–4: ");
        int menu = input.nextInt();
        switch (menu) {
            case 1: System.out.println("Java"); break;
            case 2: System.out.println("C++"); break;
            case 3: System.out.println("Python"); break;
            case 4: System.out.println("exit"); break;
            default: System.out.println("Invalid menu");
        }
        input.close();
    }
}

Marks use ranges
Write a program that reads a mark and displays a grade using if / else if / else. Test from the highest threshold down. A switch case cannot express mark >= 90.
SYNTAX · Click a highlighted part to explore it
if () { /* Excellent */ }
else if (mark >= 80) { /* Very Good */ }
else if (mark >= 70) { /* Good */ }
else if (mark >= 50) { /* Pass */ }
else { /* Fail */ }
Lecture scale: 90–100 Excellent; 80–89 Very Good; 70–79 Good; 50–69 Pass; 0–49 Fail. Assume an integer mark in 0–100.
Read a mark, then choose one grade
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Mark: ");
        int mark = input.nextInt();
        if (mark >= 90) {
            System.out.println("Excellent");
        } else if (mark >= 80) {
            System.out.println("Very Good");
        } else if (mark >= 70) {
            System.out.println("Good");
        } else if (mark >= 50) {
            System.out.println("Pass");
        } else {
            System.out.println("Fail");
        }
        input.close();
    }
}

Complete nested-if solution
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int a = input.nextInt();
        int b = input.nextInt();
        int c = input.nextInt();
        int largest;
        if (a >= b) {
            if (a >= c) largest = a;
            else largest = c;
        } else {
            if (b >= c) largest = b;
            else largest = c;
        }
        System.out.println("Largest = " + largest);
        input.close();
    }
}

Choose the right decision

    case 2: language = "C++"; break;
