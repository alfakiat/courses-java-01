Keywords and reserved literals

51Reserved keywords

Includes class, public, and _.

3Reserved literals

true, false, null are literals, not keywords.

2Unused keywords

const and goto are included in the 51.

About the “55 reserved words” count

The slide count mixes categories and double-counts the two unused keywords. Java 8 had 50 keywords (including const and goto) plus 3 literals. Java 9 added the reserved underscore. Modern Java also has contextual keywords such as var and record.
