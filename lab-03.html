Introduction

In this lab, students will practice the basic operators of Java. They will use arithmetic, relational, logical, and assignment operators, understand the order in which operators are evaluated..

Pre-Lab Preparation

Review variables and primitive data types, the difference between the assignment operator (=) and the equality operator (==), and print statements.

Task 01

Write a java program that finds and print the semester GPA and print it, where a student had 12 hours (4 courses) for the first semester, marks : 80 , 85, 90, 91. Using addition, subtraction, multiplication, integer division.

● ● ●Required equation
GPA = total marks / total hours
● ● ●Given values · code inside main()
int mark1 = 80, mark2 = 85, mark3 = 90, mark4 = 91;
int totalHours = 12;
// Calculate and print GPA using the required operators.

Task 02

Use the increment (++) and decrement (--) operators in prefix and postfix forms to find the value of z, where x= 5 , y= 6. Evaluate the expression shown below.

● ● ●Trace the expression · code inside main()
int x = 5, y = 6;
int z = x++ * ++y;
// Find z and track the final values of x and y.

Task 03

Use the remainder operator (%) to determine whether a number is even or odd and whether it is divisible by another number.

● ● ●Operator patterns · choose your own number and divisor
number % 2 == 0
number % divisor == 0
// Use a nonzero divisor.

Task 04

Write a program that checks whether a student is eligible for an exam. The student must have attendance of at least 75 and a mark of at least 40. Declare attendance = 82 and mark = 55, then combine the conditions using the logical AND operator (&&). Display the result.

● ● ●Given values · code inside main()
int attendance = 82;
int mark = 55;
// Combine the two required conditions using &&.
// Display the result.

Task 05

Find the result, where a =5, b=2. Explain which operator Java evaluates first in each expression.

● ● ●Evaluate in order · code inside main()
int a = 5, b = 2;
b += 10;
System.out.println((a + b) * 6);
System.out.println(a + 10 > 12 && 3 * b == 6);
// Explain operator precedence in each expression.
