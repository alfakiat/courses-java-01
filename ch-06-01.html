Replace repeated lines with a loop

A loop repeats a block while its boolean condition is true. Each run of the body is one iteration. Today: while checks first; do-while checks last. For loops come later.

Print Hello three times

Java · inside main()
int count = 1;
while (count <= 3) {
    System.out.println("Hello");
    count++;
}
System.out.println("Finished");

04 / 12 · Chapter 6.111–15 min · 4 minutes
Read a limit. Print the even numbers.
Read N, then move through 2, 4, 6, … up to N. If N is below 2, display a message. Assume the user enters an integer.
Scanner examples are complete Main.java programs. The supplied input is shown separately from program output; typed input is not echoed by Java itself.
A while loop with an update of 2
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("N: ");
        int n = input.nextInt();
        if (n < 2) {
            System.out.println("No even numbers from 2 to N");
        } else {
            int even = 2;
            while (even <= n) {
                System.out.print(even + " ");
                even += 2;
            }
            System.out.println();
        }
        input.close();
    }
}

Keep asking until input is valid
A prompt should appear at least once. Repeat while the mark is invalid: below 0 OR above 100. Stop when both invalid conditions are false. Assume integer input.
Accept only marks from 0 to 100
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int mark;
        do {
            System.out.print("Mark (0-100): ");
            mark = input.nextInt();
        } while (mark < 0 || mark > 100);
        System.out.println("Accepted: " + mark);
        input.close();
    }
}

08 / 12 · Chapter 6.125–29 min · 4 minutes
Stop at zero. Count the other numbers.
Zero is a sentinel: it means stop, not a value to count. Positive and negative non-zero numbers both increase the count. Read first, count if needed, then check whether to repeat.
Count non-zero entries
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int number;
        int count = 0;
        do {
            System.out.print("Number (0 to stop): ");
            number = input.nextInt();
            if (number != 0) {
                count++;
            }
        } while (number != 0);
        System.out.println("Count: " + count);
        input.close();
    }
}

09 / 12 · Chapter 6.129–33 min · 4 minutes
A menu that repeats until Exit
Show the menu at least once. Options 1 and 2 print messages; option 3 ends repetition. Other values print Invalid choice. A switch break leaves the switch; the loop condition decides whether the menu repeats.
Choose, act, then show the menu again
Main.java · complete program
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        int choice;
        do {
            System.out.println("1. Print Hello");
            System.out.println("2. Print Welcome");
            System.out.println("3. Exit");
            System.out.print("Choice: ");
            choice = input.nextInt();
            switch (choice) {
                case 1: System.out.println("Hello"); break;
                case 2: System.out.println("Welcome"); break;
                case 3: System.out.println("Goodbye"); break;
                default: System.out.println("Invalid choice");
            }
        } while (choice != 3);
        input.close();
    }
}

Find the loop mistake
A missing update can keep a condition true forever. Also check the boundary, braces and stray semicolons. The preview below stops after three iterations; the incorrect program would keep repeating.
Use braces to include both the action and the update. Do not put a semicolon after while(condition): it creates an empty loop body. Keep the final semicolon in do-while.

Leave the loop, or skip one iteration
break exits the nearest loop immediately. continue skips the rest of this iteration and returns to the condition. In a while loop, make sure the update still happens before continue.
break stops before printing 4
Java · inside main()
int i = 1;
while (i <= 6) {
    if (i == 4) {
        break;
    }
    System.out.print(i + " ");
    i++;
}
Console output
continue skips 4, then carries on
Java · inside main()
int i = 0;
while (i < 6) {
    i++;
    if (i == 4) {
        continue;
    }
    System.out.print(i + " ");
}
