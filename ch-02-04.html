CHAPTER TWO · 04 / 06

Identifiers & Naming Conventions

Choose names that compile, then make those names easy for other developers to read.

COMPILER RESTRICTIONS

Identifier checklist

  • Letters, digits, $ and _

    ASCII examples are shown here. Java also supports Unicode letters and digits.

    student2 · $total · _count
  • Never begin with a digit

    item2 ✓ 2item ✕

  • Case matters

    score and Score are different identifiers.

  • Avoid reserved names

    class · true · null · _ ✕

    Keywords and literals cannot be names. A lone underscore is reserved in modern Java.
