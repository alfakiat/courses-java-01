CHAPTER TWO · 06 / 06

Laboratory Task

Put your new skills together: reproduce a retail receipt using Java console output.

YOUR CHALLENGE

Retail Billing System

Create RetailBill.java and print the receipt exactly as shown. Use the standard main method and System.out.println.

  1. Declare a public class named RetailBill.
  2. Add the main entry point.
  3. Print all six lines, preserving spaces, punctuation, and dollar signs.
  4. Compile with javac RetailBill.java, then run java RetailBill.

For this exercise, print the provided totals as text. Tax is 16% of $150.00: $24.00.

EXPECTED OUTPUT
● ● ● RetailBill · console
====================
Item: 27-inch Display Monitor
Subtotal: $150.00
Tax (16%): $24.00
Grand Total: $174.00
====================

Six lines. One complete receipt.

Reveal a sample solution
public class RetailBill {
    public static void main(String[] args) {
        System.out.println("====================");
        System.out.println("Item: 27-inch Display Monitor");
        System.out.println("Subtotal: $150.00");
        System.out.println("Tax (16%): $24.00");
        System.out.println("Grand Total: $174.00");
        System.out.println("====================");
    }
}
