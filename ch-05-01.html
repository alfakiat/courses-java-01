Predict the output
int x = 4;
if (x > 5) {
    System.out.println("A");
}
System.out.println("B");
Reveal answer & explanation
B
The condition is false, so A is skipped. B is outside the block.
Independent if statements or one chain?
int mark = 95;
if (mark >= 50) {
    System.out.println("Pass");
}
if (mark >= 90) {
    System.out.println("Excellent");
}
Reveal answer & explanation
Pass
Excellent
Both independent conditions are true. An if / else if chain would select only its first true branch.
Find the extra semicolon
int mark = 30;
if (mark >= 50);
{
    System.out.println("Pass");
}
Reveal answer & explanation
Pass
The semicolon is an empty statement controlled by if. The following block runs unconditionally. Remove the semicolon.
Why use braces?
int mark = 30;
if (mark >= 50)
    System.out.println("Pass");
    System.out.println("Certificate");
Reveal answer & explanation
Certificate
Without braces, only the immediately following statement belongs to if. Indentation does not define a Java block. Put both statements inside braces to control both.

Assume valid, nonnegative input. Test (100, true), (100, false), and (99, true): 20%, 10%, and no discount.
Choose if for an optional action, if-else for two alternatives, else if for ordered alternatives, and nested if for dependent decisions.
