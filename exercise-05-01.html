Question 01

Write a Java program. Set temperature to 35. If it is greater than 30, print "Hot day".

Question 02

Write a Java program. Set mark to 50. If mark is 50 or more, print "Pass". Always print "Finished" at the end.

Question 03

Write a Java program that asks for an age. If the age is 18 or more, print "You are a young man.".

Question 04

Write a Java program that asks for a mark. Print "Pass" if the mark is 50 or more. Otherwise, print "Fail".

Question 05

Write a Java program that asks for a whole number. Print "Even" if it is even. Otherwise, print "Odd".

Question 06

Write a Java program that asks for a whole number. Print "Positive", "Negative", or "Zero".

Question 07

Write a Java program that asks for a mark and attendance percentage. Print "Eligible" if the mark is 85 or more and attendance is 80 or more. Otherwise, print "Not eligible".

Question 08

Write a Java program that asks for a mark. Print the grade: 90–100 = "Excellent", 80–89 = "Very Good", 70–79 = "Good", 50–69 = "Pass", and 0–49 = "Fail".

Question 9

Write a Java program that asks for a whole number. If it is positive, print "Positive Even Number" or "Positive Odd Number". Otherwise, print "Number is not positive".

Question 10

Write a Java program that asks for a purchase amount and whether the customer is a member. If the amount is 100 or more, give members 20% off and other customers 10% off. If it is below 100, print "No discount.".

Question 11

Write a Java program that asks for a mark. If it is below 0 or above 100, print "Invalid mark". Otherwise, print the grade using the rules in Question 8.

Question 12

Write a Java program that asks for a purchase amount and membership status. Use the discount rules in Question 10. Print the discount amount and the final bill. If the amount is negative, print "Invalid amount".
