Reference Types

Different reference types, one shared idea: the variable holds a reference rather than the object itself.

REFERENCE TYPE

Strings

Immutable sequences of characters.

String s = "Hello";
Explore features

String objects cannot be modified. Assigning s to a different string changes the reference, not the original string.

REFERENCE TYPE

Arrays

Fixed-length sequences of one component type.

int[] nums = {1, 2, 3};
Explore features

The array object is allocated on the heap. nums.length is 3; indices run from 0 to 2. Elements can change, but its length cannot.

REFERENCE TYPE

Classes & Objects

Classes define types; objects are instances.

class User { }
User u = new User();
Explore features

The variable u holds a reference to a User instance. The new expression creates the object.

REFERENCE TYPE

Interfaces

Contracts that support polymorphism.

// Imports: java.util.List, java.util.ArrayList
List<String> names = new ArrayList<>();
Explore features

List is the declared interface type. ArrayList is the concrete implementation. The reference can hold an instance of a compatible implementation.

One object, multiple references

int[] first = {1, 2, 3};
int[] second = first;
second[0] = 9;
System.out.println(first[0]); // 9

Both variables refer to the same array. Assigning a reference does not copy the object.
